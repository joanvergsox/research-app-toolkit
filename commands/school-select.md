Use the `school-select` skill to recommend and compare schools based on your CV profile and preferences.

Arguments (optional):
- `region` — target region or country (e.g., UK, US, EU)
- `field` — specific research field or program type (e.g., HCI, NLP, computer vision)

If arguments are provided, use them as defaults in the personalization questions.
